# Repository Agent Instructions

Follow the repository's existing contribution instructions and any applicable
nested agent rules. For coding work, use
`skills/agentic-coding-guidelines/SKILL.md`. For repository reviews or maintenance, use
`skills/repository-maintenance/SKILL.md` alongside project-owned instructions.
For plugin, inference, multimodal, or tutorial changes, read the relevant section
of `skills/repository-maintenance/references/development.md`.
