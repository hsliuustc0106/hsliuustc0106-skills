# Markdown Profile

Use this profile for a standalone technical article rather than site
integration.

- Default to English unless another language is explicitly requested.
- Use standard Markdown headings, lists, tables, fenced code blocks, and links
  unless the target platform specifies stricter formatting.
- Derive the output filename from the approved slug or use the user-provided
  path. Do not overwrite an existing file without confirming that it is the
  intended target.
- Keep citations adjacent to supported claims and include a references section.
- Apply the same narrative-blueprint approval and primary-source policy as the
  core workflow.
- Validate heading order, link syntax, code-fence balance, and whitespace.
