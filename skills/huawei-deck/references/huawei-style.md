# huawei-style — 华为官方胶片排版与文案风格分析

对源仓库提供的 6 份华为官方 PPT/PDF（逐页共 152 页目检）的系统性分析：**版式怎么排、字怎么写**。做「更像华为官方」的 deck 时按本文执行；提取出的封面/logo/组件素材在 `assets/huawei-refs/`（有独立 README 索引）。本文与 `design-system.md`（本模板自身的设计系统）互补——冲突时以 design-system.md 的硬规为准，本文提供官方风格的参照与升级方向。

分析样本：官方标准空白模板（浅色 16:9）、eKit KV 封面、高空抛物解决方案（14 页）、iMasterCloud DME IQ 产品胶片（37 页，**深色系**）、ICT 学院课程胶片（21 页）、ICT 人才生态胶片（62 页）、英文存储发布会胶片（12 页）。

## 1. 两套配色公式（最强识别特征）

**浅色系（主流，5/6 份）：白底 + 灰结构 + 红焦点。**

- 白/浅灰底；灰阶承担全部结构（灰底卡、灰题条、大灰数字、灰色正文）；华为红（#C7000B～#CE0E2D）只做焦点。
- 红色仅允许出现在 7 类位置：① 页标题（部分 deck）② 正文关键词红黑混排 ③ 关键数字 ④ 流程/阶段标签与箭头 ⑤ 小面积红底白字条幅 ⑥ 装饰线（短下划线、角线、弧线）⑦ 行动按钮/CTA。**大面积红底几乎不用**——红底白字块永远是小条幅。
- 点缀色极少且饱和度压低：矩阵表列头可用极浅紫/黄/蓝/粉区分领域；非华为主体的曲线用绿/灰，红色留给结论。
- 官方图表配色规范（见 `assets/huawei-refs/pages/官方模板-图表配色示范页.jpg`）：柱状图 = 灰阶做底 + 华为红标强调项 + 深红/琥珀点缀；对比表用 红点=华为、灰点=友商。

**深色系（DME 产品胶片）：黑底 + 白字 + 金强调 + 红点缀。**

- 内容页纯黑/近黑底（#000–#0D0D0D），深灰卡片（#1E1E1E–#2A2A2A）靠明度差而非线框分区。
- **金琥珀色（#E8A33D–#FFBF00）才是深色页的工作色**：卡片小标题、关键词、数字、URL、栏头全用金色；红色只做品牌锚点与方向性元素（logo、粗箭头、上升箭头、红勾、目录高亮）。
- 目录页反色成浅灰，形成「黑-灰-黑」章节呼吸；真实产品截图（浅色 UI）嵌深色样机，充当黑底上的亮块焦点。

## 2. 页面骨架

- **标题区**：恒定左上角，单行为主、超长自然折两行**不缩字号**；约 40–44pt 粗体；无底色块、无装饰线（红色粗体字本身就是装饰）。浅色 deck 标题有两派：红色标题派（ICT 系）与黑色标题派（方案汇报/英文发布会）；封面与 Thank you 标题一律黑色——「红色标题只用于内容页」。
- **页脚三件套**（每页位置像素级一致）：左下页码 + 密级声明（Huawei Confidential / Huawei Proprietary – Restricted Distribution），右下华为花瓣 logo + HUAWEI 字标；封面用「Security Level:」占位，结尾页全部去除——页脚出现规则本身就是页型信号。发布会风格变体：左下放会议主题 logo + 口号。
- **正文网格**：主导 3–6 等分栏卡片；复杂信息用「行头 × 彩色列头」矩阵表；B2B 方案页固定「痛点问题（窄）| 方案主体（宽）| 关键价值（窄）」1-2-1 三段，或「过去 → 现在」对比双柱。
- **留白与密度**：观点页留白极大（单一大图形居中），证据页密度极高（卡片可到 30+ 个）但靠网格对齐与统一卡片样式维持秩序；密页与疏页交替出现。
- **卡片语言**：白/浅灰圆角矩形 + 极浅投影；重点卡带伪立体（3D 台面、梯形底座、台阶、金字塔、发光球）；灰白立体 + 红色点睛，复杂关系图不引入新颜色。
- **图片处理**：照片直角不圆角；重要图片只画**红色四角线框**（corner bracket）装饰，不描整框；照片墙等高横排。

## 3. 页型清单（官方惯用）

| 页型 | 版式要点 |
|---|---|
| 封面 | 全幅摄影 KV（雪山红伞为经典）+ 左上标题（黑）+ 红色直角线点缀 + 底部白条右侧 logo |
| 目录 | ① 浅灰底 + 黑「目录」+ 红短下划线；② 左竖图右条目（圆圈数字+细分隔线）。**目录页复用兼章节页**：重复出现仅切换红色高亮项 |
| 章节页 | 左图 + 右侧超大浅灰序号（01–05，顶部出血裁切）+ 黑色章节名 + 灰色子目录（当前小节红色高亮） |
| 内容页 | 左上标题 + 3–6 栏网格 / 1-2-1 三段 / 矩阵表；右上角可挂二维码位 |
| 案例页 | 五段式：灰题条（合作背景→合作过程[建立/内容/成果]→客户声音）+ 红角框实证图（证书/牌匾/校门）+ 大引号引文+署名 |
| 数据页 | 发光圆环/圆圈内大号红（金）数字三连横排 + 类别词 |
| 总结页 | 「现在(大字) vs 过去(灰小字) + 红色上升箭头」对比卡组 + 旅程轴收束全篇 |
| 结尾 | 左特大黑字「Thank you.」+ 右栏中英文使命宣言、版权、免责声明、logo；前面可加「关注我们」二维码页 |

## 4. 文案表达方式

**标题 = 观点句，不是栏目词。** 全部样本中几乎没有名词短语式标题。五种句式：

1. **判断+结果双短句**（逗号分隔）：「数智技术驱动第四次工业革命，带来前所未见的生产力跃升」「伙伴的共性诉求：提升效率、节约成本、拓宽销售管道」
2. **「功能名词：利益句」冒号双段式**：「远程运维：减少伙伴上站，让运维管理简单高效」「安全保障：用户侧不开放端口、零攻击风险，获得系列重要安全认证」
3. **单字前缀章节系统**：「课：」「书：」「训：」「赛：」——先用一页预告「课书训赛」框架，后续每页标题首字回扣框架，零页数成本实现章节导航
4. **案例公式**：「案例｜{对象}：{做法}，{价值}」——「案例｜深圳职业技术大学：课证共生共长，实现校企合作精准育人」；同族有「白皮书｜」「专刊｜」前缀
5. **数字排比标题即摘要**：「华为职业认证架构：三层技术栈，六大技术领域，22个技术方向，23类认证」

高频动词全是利他式赋能词收尾于价值：助力 / 提升 / 帮助 / 使能 / 促进 / 推动 / 共建 / 打造。自造记忆口诀常入标题：「1点2线4维」「双轮驱动」「课证共生共长」「以赛促学、以赛促教、以赛促就业」。

**正文规则：**

- 短语级碎片为主（4–12 字），完整长句只出现在页顶导语条（1–2 行铺垫）、案例叙述与 FAQ。
- 卡片小标题是**四~六字断言**，「名词+形容词」尾字定调：「交付成本高」「场景覆盖广」「迁移能力强」「类型覆盖全」。
- 关键词强调用**变色不加粗**：白句中单个名词金色/红色（可同时放大），一页 3–6 处，扫读即得重点；比整句加粗层级更细。
- 排比工整：输出列表统一句式（「转化为××」×4）；痛点页以问句收尾为方案铺垫（「如何缩短 线索→意向→下单 的流程周期？」）。
- **引文组件**是标配：大引号 + 引文 + 破折号署名（职务全称），案例页几乎每页一条，最高用到总统级引言背书；引文内关键词照样红色强调。

**数字用法：**

- 数字必大必变色：红（浅色系）/金（深色系）大号数字 + 黑色小号单位紧贴——「20.8万 员工」「37,000+ HCIE」。
- 偏爱「N+」开区间：170+ 国家、40000+ 设备、5000+ 人数、1个月+。
- 对比呈现固定为「过去(灰小) vs 现在(大字) + 红色箭头」，前后值并列（「1 周 → 0.5 天」「300 min/TB → 15 min/TB」）。
- 数字必挂权威来源或口径注脚：「2022《中国ICT人才生态白皮书》预测…」；右下角 logo 上方灰色小字「*数据截至日期：2025年8月」全 deck 统一。
- 敏感金额脱敏为「XXX」「x 万」，保留百分比。

## 5. 高复用组件（映射到本模板）

已在 34 页模板中有对应页型的：封面 KV、目录、章节页、卡片网格、对比两栏、流程条、数据大字、黑板/深色页、结语页——按本文微调文案与红色用量即可。

值得在终版制作时主动引入的官方组件：

1. **右上角二维码位**：二维码 + 一行小字用途标签（「课程目录」「报名入口」），与左上标题对角平衡，把演示变成入口。
2. **重复目录页作章节过渡**：同一版式复用、仅切换红色高亮项——HTML 模板里复制目录 section 改高亮即可。
3. **右上角三段式面包屑**：长章节（>8 页）内子章节定位，当前段红字其余灰字。
4. **「痛点 | 方案 | 价值」1-2-1 骨架**与**AS IS / TO BE 对比页**：B2B 方案叙事标准件。
5. **底部结论条**：页底立体横幅承载「权威引用 + 红色数字」单行结论，每页自带 takeaway。
6. **KPI 数字带**：图标 + 红色大数字 + 黑色小单位横排四联。
7. **红角框实证图 + 引文署名**：案例页「每个主张配一件实物证据」。
8. **数据口径脚注**与**红虚线框=新增/在建语义**（配 New 角标）。
9. **附录三件套**：兼容性矩阵表（√/×/N/A）+ 纯文字 FAQ 放在结尾页之后，正文保持轻量。

## 6. 与本模板设计铁律的关系

- 官方风格印证了铁律 3（三色体系、红只给重点）与铁律 9（标题即观点）：官方标题全部是观点句，红色使用清单比本模板还克制。
- 官方正文比本模板更碎片化（大量 4–12 字短语卡）；本模板面向授课场景保留 21px 散文底线（铁律 2），**做汇报/产品胶片风格时应向官方靠拢：短语化、变色强调、数字大字**。
- 深色页配色注意：官方深色系用**金色**做信息强调而非红色——本模板深色/黑板页如需强调大量信息，参照「黑底+白字+金强调+红点缀」公式，避免红色大面积上黑底。
