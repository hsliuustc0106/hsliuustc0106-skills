# Contributing

Before implementing a contribution intended for a PR, complete the
[contributor pre-PR check](skills/precheck-pr/SKILL.md). The human contributor
supplies the outcome, leverage, expected effect, and customer need; agents reuse
explicit answers, ask about missing ones, and wait rather than inventing them.

Preserve [AGENTS.md](AGENTS.md), repository-owned skill sources, existing human
edits, and overlapping open PRs. For skill/package changes, use
[personal-skills-review](skills/personal-skills-review/SKILL.md) to check discovery,
links, packaging, and applicable offline helper tests. Report exactly which checks
ran and their limitations.

This contributor gate does not change independent-review selection or authorize
publishing, merging, or installing skills on another computer.
